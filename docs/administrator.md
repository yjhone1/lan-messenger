# 관리자 인증과 상대방 상태 조회

## 최초 설정

각 대상 PC에서 **Tools → Utilities (This PC) → Administrator Password...**를 엽니다.
관리자 비밀번호를 12자 이상으로 설정하고 다시 입력합니다. 이후 변경에는 현재 비밀번호가 필요합니다.
공통 고정 기본 비밀번호는 없습니다. 설정하지 않은 PC는 원격 신청과 관리자 상태 조회를 허용하지 않습니다.
이 설정은 해당 PC에서 메신저를 실행하는 Windows/Linux 사용자 프로필에 저장됩니다.

다른 PC의 관리자 비밀번호를 원격으로 설정하거나 변경하는 기능은 없습니다.
여러 PC에 동일한 관리 비밀번호를 사용하려면 각 PC에서 직접 설정하십시오.
저장된 인증값도 비밀 정보이므로 OS 사용자 프로필과 설정 파일에 대한 접근 권한을 보호해야 합니다.

## 원격 제어 신청

1. 상대방의 Remote Desktop 메뉴나 버튼을 선택합니다.
2. **대상 PC에 설정된 관리자 비밀번호**를 입력합니다.
3. 상대 PC가 인증을 검증한 뒤에만 수락/거절 창을 표시합니다. 틀린 비밀번호나 인증값 없는 요청은 창을 띄우지 않고 거절합니다.
4. 사용자가 수락하면 기존 32자리 호스트 확인 코드, TLS, 일회용 접속 토큰 절차를 진행합니다.

관리자 비밀번호만으로 상대방의 사용자 동의를 생략하거나 화면을 자동으로 제어할 수는 없습니다.
양쪽 메신저를 새 버전으로 업데이트해야 합니다. 구버전의 비인증 원격 요청은 거절합니다.

## 상대방 상태 확인

1. 상대방의 **사용자 정보 → 관리자 상태 조회** 탭을 엽니다.
2. **관리자 비밀번호로 상태 조회 / 새로고침**을 누릅니다.
3. 대상 PC의 관리자 비밀번호로 인증하면 다음을 읽기 전용으로 확인합니다.

- 현재 메신저 연결과 수신 가능 상태
- 에이전트 감시 동작 여부 및 현재 허용/차단 설정
- AI 에이전트 차단 성공·실패 기록과 실패 사유
- 네트워크·원격 화면 연결 상태 및 운영 오류
- 기록별 한국시간(KST) 시각 (원문 JSON에는 UTC 시각 유지)

기본 **보고서** 화면은 조회 대상 사용자·PC 이름·IP·메신저 버전, 조회 시각, 연결·감시 상태와 에이전트 정책을 표로 표시합니다.
운영 기록 표에는 발생 시각·구분·종류·한글 설명·기록 원문을 나란히 표시합니다. 알려진 오류만 설명을 붙이며, 없는 정보는 `정보 없음`으로 표시합니다.
**원문 JSON** 탭에서 상대 PC가 제공한 내용을 그대로 확인할 수 있습니다. 대상 사용자·PC·버전은 사용자 정보에서 가져온 값이며, 운영 상태는 인증된 조회 응답 기준입니다.
이 보고서는 Windows 충돌 보고서나 실시간 감시 화면이 아닙니다. 자동 종료 원인은 실제 종료 시각의 Windows 오류 기록과 대조해야 합니다.

새로고침할 때마다 인증하며, 표시된 결과는 60초 후 잠깁니다. 다른 사용자의 정보로 전환하거나 창을 닫으면 이전 조회 내용을 유지하지 않습니다.
인증 응답을 받지 못하면 약 15초 후 시간 초과로 표시합니다. 잘못된 인증을 제출한 피어는 30초 동안 재시도가 제한됩니다.
에이전트 설정을 원격으로 변경하는 기능은 계속 금지합니다.

## 기록 범위

`/trace`를 켜지 않아도 최근 운영 기록을 **최대 200개** 보관합니다.
기록은 로컬 로그 폴더의 `admin-events.json`에 저장하며, 전체 디버깅 로그를 그대로 내보내지 않습니다.
채팅 내용·비밀번호·키·원격 확인 코드를 조회 정보에 포함하지 않습니다.
이 버전에서 수집을 시작한 운영 기록만 조회할 수 있으며, 과거 버전에서 기록하지 않은 사건을 복구하지 않습니다.

차단 설정과 실제 종료 성공은 별개입니다. 권한 부족으로 종료하지 못한 경우 실패 기록을 확인하십시오.
Linux 성공 기록은 SIGTERM 전달 성공을 뜻하므로 프로세스가 실제 종료했는지도 확인해야 합니다.

## 인증 방식

관리자 비밀번호 원문은 저장하거나 전송하지 않습니다. 로컬에는 무작위 salt와 PBKDF2-HMAC-SHA256 인증값을 저장합니다.
각 작업은 피어·대상·목적에 결합된 30초 유효 일회용 challenge와 HMAC 증명을 사용합니다.
다른 작업에 인증값을 재사용하거나 만료·소비된 인증값을 제출하면 거절합니다.
조회 응답은 인증에서 얻은 키와 분리한 AES-256-GCM 키로 추가 암호화하고, 요청 식별값에 결합하여 변조와 다른 요청의 응답 재사용을 거부합니다.

## 웹 프리뷰

웹에서도 유틸리티의 **프리뷰 관리자 비밀번호**를 설정한 뒤 인증 흐름을 미리 볼 수 있습니다.
브라우저 설정은 실제 데스크톱 PC의 비밀번호와 별개이며, 실제 상대방의 기록을 조회하거나 원격 권한을 부여하지 않습니다.
