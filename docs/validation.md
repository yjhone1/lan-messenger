# 수정 및 검증 결과

2026-11-20, 기준 커밋 737f547 이후 로컬 작업.

## 반영

- 로컬 Tools → Utilities (This PC) 아래 AI 에이전트 설정 및 캡처.
- 원격 유틸리티 정책 송수신 제거, 구버전 원격 정책 메시지 무시.
- 최초 설치·누락된 항목은 모두 허용. 명시적으로 저장한 설정은 유지.
- 로컬 정책 CLI, 성공·실패 로그 및 설정 창의 종료 결과 표시.
- 종료 시 감시 중단, Windows 삭제 시 모든 정책 허용 저장.
- 캡처 웹 소스는 src/capture/로 통합, 네이티브 소스는 lmc/src/capture/에 유지.
- 원격 화면: TLS 1.2+, 인증서 지문 고정, 별도 경로의 32자리 확인 코드와 일회용 토큰, 인증 전 데이터 차단.
- Strict: OAEP-SHA256, AES-256-GCM, 방향별 키, 순서 번호, 변조·재전송·반사 거부.
- 메시지 길이 상한 및 Strict 연결 식별 문자열 분할 수신 처리.
- 웹 시뮬레이션의 고정 비밀번호 제거 및 실제 보안 검증과의 구분.
- 로컬 관리자 비밀번호 설정·변경, 대상 PC의 인증 검증 후에만 원격 신청 수락 창 표시.
- 사용자 정보의 관리자 상태 조회 탭: 매번 비밀번호 인증, 읽기 전용, 60초 후 잠금.
- `/trace`와 독립적인 최근 200개 운영 기록 저장 및 인증된 암호화 조회.
- 인증값은 피어·대상·목적에 결합한 30초 유효 일회용 challenge이며, 비밀번호 변경 시 기존 challenge를 무효화.

## 검증 범위

Windows 실행 파일·설치 프로그램의 빌드 및 실제 삭제는 이 환경에서 수행하지 않았습니다.
삭제 스크립트의 실행 파일 경로 인용과 실행 중 인스턴스 확인 경로를 보완했습니다.
물리적 두 PC의 화면 공유·입력 재현은 미검증이며, 원격 테스트는 로컬 TLS 통합 테스트입니다.
Legacy CBC와 채팅 공개키 교환의 영구 신원 인증 한계는 README를 참고하십시오.
자동 배포 또는 Windows 릴리스 발행은 이 검증 범위에 포함하지 않습니다.

추가 관리자 기능은 `/tmp/lmc-admin-review`에서 빌드하고 검증했습니다.
두 실제 PC 사이의 관리자 조회 및 Windows GUI·설치 파일 검증은 수행하지 않았습니다.

빌드·CTest·격리 프로세스 검사 로그는 build-review/verification/에 보관합니다.
